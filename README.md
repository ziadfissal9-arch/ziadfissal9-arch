### About Me

I'm a full-stack developer who enjoys turning rough ideas into polished, production-grade products — real backends, typed end-to-end, tested, and actually deployed, not just prototypes. Every project below ships with a live demo, a written test suite, and a README you can read in five minutes.

- 🔭 Currently building full-stack apps with **React, TypeScript, Node.js, and Postgres/MongoDB**
- 🎯 Focused on clean architecture, accessibility, and interfaces that feel considered rather than generic
- 🌱 Always sharpening backend fundamentals — auth, data modeling, deployment pipelines
- 💬 Open to internships, junior roles, and freelance front-end/full-stack work
